Thank you for your interest in contributing to presume! Discussions and issues are welcome, provided they follow the project's code of conduct and are not made via automated tools.

This project will not generally accept pull requests without prior communication. If you would like to add a feature or fix a bug, please open an issue first to discuss the feature and its potential implementation _before_ trying to implement the feature. Drive-by PRs will most likely be closed.

Automated AI agents are not welcome in this project. Interactions made primarily or entirely through automated agents will result in a ban from the project.

This project will never pay bounties for features or bug fixes.

The use of AI tools for code generation is permitted within reason and with prior discussion and coordination. One-shot prompted implementations will most likely be rejected. When in doubt, please ask.
